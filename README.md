# SimpleStates

SimpleStates builds StateMirror.

StateMirror preserves what an application knew when it acted.

## StateMirror

[StateMirror Core](https://github.com/simplestates/statemirror-core) is the Apache-2.0 self-hosted evidence engine for capturing, retrieving and verifying application decision evidence.

State is queried. Decisions are made. Actions remain application-owned.
